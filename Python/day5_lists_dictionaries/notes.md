## What is a List?

A list is used to store multiple values in a single variable.

Example:

```python
fruits = ["Apple", "Banana", "Orange"]
```

---

## Common List Methods

### append()

Adds an item.

```python
fruits.append("Mango")
```

### remove()

Removes an item.

```python
fruits.remove("Banana")
```

### len()

Returns length.

```python
len(fruits)
```

---

## What is a Dictionary?

A dictionary stores data as key-value pairs.

Example:

```python
student = {
    "name": "John",
    "age": 22
}
```

---

## Accessing Dictionary Values

```python
student["name"]
```

## Interview Questions

### What is a List

A list is an ordered collection used to store multiple items.

### What is a Dictionary

A dictionary stores data in key-value pairs.

### Difference Between List and Dictionary?

| List | Dictionary |
|--------|--------|
| Ordered collection | Key-value collection |
| Uses indexes | Uses keys |
| Example: [1,2,3] | Example: {"name":"John"}
