# Expense Tracker

A simple command-line Expense Tracker built using Python fundamentals.

## Features

- Add expenses
- View all expenses
- Calculate total spending
- Exit program

## Concepts Used

- Variables
- Input/Output
- Data Types
- If/Else
- Loops
- Lists
- Dictionaries
