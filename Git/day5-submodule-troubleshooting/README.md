# Day 5 - Git Submodule Troubleshooting

## Objective

Learn how Git submodules work, why they are created accidentally, how to identify them, and how to convert them back into normal folders.

## Topics Covered

- Nested Git Repository
- Git Submodule
- Submodule Errors
- Removing a Submodule
- Converting a Submodule into a Normal Folder

## Files

- notes.md
- nested-repository.md
- submodule-error.md
- remove-submodule.md
- convert-normal-folder.md

## Outcome

After completing this lesson, you will be able to:

- Understand what a Git submodule is.
- Identify nested repositories.
- Fix common submodule errors.
- Convert a submodule back into a normal folder.
