# Git Cheat Sheets

## Objective

This folder contains quick reference guides for frequently used Git commands and troubleshooting steps.

These notes are designed for fast revision before coding sessions, interviews, or resolving Git issues.

## Contents

- Daily Git Workflow
- File Recovery Commands
- Git Troubleshooting
- Common Git Mistakes

## Outcome

After using these cheat sheets, you should be able to:

- Perform your daily Git workflow confidently.
- Recover deleted files and folders.
- Troubleshoot common Git problems.
- Avoid beginner Git mistakes.
