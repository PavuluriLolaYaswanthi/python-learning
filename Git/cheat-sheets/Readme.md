# Git Cheat Sheets

## Objective

This folder contains quick reference guides for the Git commands, workflows, and troubleshooting techniques learned throughout the Git learning roadmap.

These cheat sheets are designed for:

- Quick revision before coding
- Interview preparation
- Daily Git usage
- Troubleshooting common Git issues

---

## Contents

### 1. Daily Git Workflow

A step-by-step workflow for working on projects using Git, including branching, committing, merging, and pushing changes.

---

### 2. Recovery Cheat Sheet

Quick commands to recover deleted files and folders from Git history.

### 3. Troubleshooting Cheat Sheet

Solutions for common Git problems such as:

- Submodule errors
- Nested repositories
- Missing files
- Repository status checks

---

### 4. Branching Cheat Sheet

Frequently used commands for:

- Creating branches
- Switching branches
- Renaming branches
- Deleting branches

---

### 5. Merging Cheat Sheet

Commands for:

- Merging branches
- Viewing merge history
- Resolving merge conflicts
- Aborting merges

---

### 6. Command Summary

A single-page reference containing the most commonly used Git commands.
