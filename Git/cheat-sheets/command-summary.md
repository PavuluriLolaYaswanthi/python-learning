# Git Command Summary

## Repository

```powershell
git init
```

---

## Status

```powershell
git status
```

---

## Add Files

```powershell
git add .
```

---

## Commit

```powershell
git commit -m "message"
```

---

## Push

```powershell
git push origin main
```

---

## Remote

```powershell
git remote -v
```

---

## History

```powershell
git log --oneline
```

---

## Restore Folder

```powershell
git checkout <commit-id> -- folder
```

---

## Branches

```powershell
git branch

git switch branch-name

git switch -c branch-name
```

---

## Merge

```powershell
git merge branch-name
```

---

## PowerShell

```powershell
Test-Path

Get-ChildItem

Remove-Item

tree /f
```
