# Git File Recovery Notes

## What is File Recovery?

Git stores every committed version of your project.

Even if a file or folder is deleted, Git can restore it from a previous commit.

---

## Why Use Git Recovery?

Git recovery helps you:

- Recover deleted files
- Recover deleted folders
- Restore previous versions
- Undo accidental deletions
- Restore project history

---

## How Recovery Works

↓

## What You Need Before Recovery

You need:

- Commit ID
- File or Folder Path

Commit ID


Folder


---

## Best Practices

- Commit your work frequently.
- Use meaningful commit messages.
- Never panic after deleting files.
- Check commit history first.
- Verify before committing recovered files.
