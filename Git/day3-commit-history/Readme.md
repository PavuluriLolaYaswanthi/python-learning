# Day 3 - Commit History

## Objective

Learn how to view the history of commits in a Git repository.

## Topics Covered

- What is commit history?
- View all commits
- View recent commits
- View commit history of a specific file or folder

## Files

- notes.md
- git-log.md
- folder-history.md

## Outcome

After completing Day 3, you should be able to:

- View complete commit history
- View recent commits
- Find when a file or folder was modified
- Recover deleted files using commit history
