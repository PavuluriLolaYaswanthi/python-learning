# Pull Request (PR)

## What is a Pull Request?

A Pull Request (PR) is a request to merge your changes into another branch, usually `main`.

It allows teammates to review your code before merging.

---

## Pull Request Workflow

Create Branch

↓

Develop Feature

↓

Commit Changes

↓

Push Branch

↓

Open Pull Request

↓

Code Review

↓

Approve

↓

Merge

---

## Example

```powershell
git switch -c feature-login

git add .

git commit -m "Add login page"

git push origin feature-login
```

Then open GitHub and create a Pull Request.

---

## Benefits

- Code Review
- Better Collaboration
- Prevent Bugs
- Track Discussions
