# GitHub Collaboration Notes

## What is GitHub Collaboration?

GitHub Collaboration is the process of multiple developers working together on the same project using Git and GitHub.

Each developer works independently and shares changes through GitHub.

---

## Why Collaboration?

Collaboration allows teams to:

- Work simultaneously.
- Track changes.
- Review code.
- Prevent conflicts.
- Maintain project quality.

---

## Typical Team Workflow

Developer

↓

Clone Repository

↓

Create Branch

↓

Develop Feature

↓

Commit Changes

↓

Push Branch

↓

Create Pull Request

↓

Code Review

↓

Merge into Main

---

## Collaboration Commands

Clone Repository

```powershell
git clone <repository-url>
```

Fetch Changes

```powershell
git fetch
```

Pull Changes

```powershell
git pull origin main
```

Push Changes

```powershell
git push origin feature-login
```

---

## Best Practices

- Pull before starting work.
- Use feature branches.
- Commit frequently.
- Write meaningful commit messages.
- Open Pull Requests for review.
