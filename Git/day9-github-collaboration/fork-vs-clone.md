# Fork vs Clone

## What is a Fork?

A fork creates your own copy of someone else's GitHub repository under your GitHub account.

Used mainly for:

- Open-source contributions
- External repositories

---

## What is a Clone?

A clone downloads a repository to your local computer.

---

## Difference

| Feature | Fork | Clone |
|----------|------|--------|
| Creates a GitHub copy | ✅ | ❌ |
| Downloads locally | ❌ | ✅ |
| Used for open source | ✅ | ❌ |
| Used for team repositories | Sometimes | ✅ |
