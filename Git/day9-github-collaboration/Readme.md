# Day 9 - GitHub Collaboration

## Objective

Learn how developers collaborate using GitHub repositories.

## Topics Covered

- Clone a repository
- Fetch changes
- Pull changes
- Fork vs Clone
- Pull Requests (PR)
- Collaboration Workflow

## Files

- notes.md
- git-clone.md
- git-fetch.md
- git-pull.md
- fork-vs-clone.md
- pull-request.md
- collaboration-workflow.md

## Outcome

After completing this lesson, you will be able to:

- Clone GitHub repositories.
- Download the latest changes.
- Understand the difference between Fetch and Pull.
- Contribute to team projects.
- Create and review Pull Requests.
