# Day 8 - Git Merging

## Objective

Learn how to merge branches, understand different types of merges, and resolve merge conflicts.

## Topics Covered

- What is Merging?
- git merge
- Fast-Forward Merge
- Three-Way Merge
- Merge Conflicts
- Conflict Resolution

## Files

- notes.md
- git-merge.md
- fast-forward.md
- merge-conflicts.md

## Outcome

After completing this lesson, you will be able to:

- Merge branches into the main branch.
- Understand Fast-Forward and Three-Way merges.
- Resolve merge conflicts.
- Complete feature development using Git branches.
