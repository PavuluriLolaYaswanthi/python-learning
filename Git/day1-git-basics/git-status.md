# git status

## Purpose

Shows the current state of your repository.

---

## Syntax

```powershell
git status
```

---

## Example

```powershell
git status
```

---

## Possible Outputs

### Untracked files

```text
Untracked files:
```

Git found new files.

---

### Changes not staged

```text
Changes not staged for commit
```

Files were modified.

---

### Changes to be committed

```text
Changes to be committed
```

Files are staged.

---

### Working tree clean

```text
nothing to commit, working tree clean
```

Everything is saved.

---

## When to Use

Always run:

```powershell
git status
```

before every commit.
