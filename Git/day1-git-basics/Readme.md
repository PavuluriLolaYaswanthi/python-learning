# Day 1 - Git Basics

## Objective

Learn the fundamental Git commands required to start tracking a project and upload it to GitHub.

## Topics Covered

- What is Git?
- Initialize a repository
- Check repository status
- Stage files
- Create commits
- Push code to GitHub

## Files

- notes.md
- git-init.md
- git-status.md
- git-add.md
- git-commit.md
- git-push.md

## Outcome

After completing Day 1, you should be able to:

- Create a Git repository
- Track project files
- Save project history
- Upload your code to GitHub
