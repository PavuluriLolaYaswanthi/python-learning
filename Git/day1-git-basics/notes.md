# Git Basics Notes

## What is Git?

Git is a distributed version control system.

It allows developers to:

- Track changes
- Save project history
- Collaborate with others
- Restore previous versions

---

## Why Use Git?

Without Git:

- No history
- Difficult collaboration
- Easy to lose work

With Git:

- Complete history
- Easy rollback
- Safe collaboration
- Professional workflow

## Key Terms

Repository

A folder tracked by Git.

Commit

A snapshot of your project.

Stage

Preparing changes before committing.

Remote

The GitHub repository connected to your local repository.

Origin

Default name of the remote repository.

Main

Default branch.
