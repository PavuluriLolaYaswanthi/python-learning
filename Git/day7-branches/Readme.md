## Objective

Learn how Git branches work and how to create, switch, list, rename, and delete branches.

## Topics Covered

- What is a Branch?
- Why Branches are Important
- Create Branches
- Switch Branches
- View Branches
- Rename Branches
- Delete Branches
- Branch Workflow

After completing this lesson, you will be able to:
