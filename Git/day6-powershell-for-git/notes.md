# PowerShell Notes for Git

## Why Learn PowerShell?

PowerShell helps you manage files and folders while working with Git.

Git handles version control.

PowerShell helps you:

- Check folders
- Find files
- Delete files
- Verify repository structure
- Troubleshoot Git issues

---

## Commands Learned

- Test-Path
- Get-ChildItem
- Remove-Item
- tree

---

## When We Used Them

During Git troubleshooting we used them to:

- Verify if folders existed.
- Check hidden `.git` folders.
- Delete nested Git repositories.
- Display project structure.
