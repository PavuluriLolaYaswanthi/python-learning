# tree Command

## Purpose

Displays the folder structure of a project.

---

## Syntax

```powershell
tree
```

---

## Show Folder Structure

```powershell
tree
```

---

## Show Folder Structure with Files

```powershell
tree /f
```

---

## Example

```powershell
tree /f
```

Output

```text
python-learning
│
├── Git
│
├── Python
│   ├── day1_variables
│   ├── day2_conditions
│   ├── day3_loops
│   └── day4_functions
│
└── Projects
```

---

## Why Use tree?

- View project structure
- Verify folders
- Check repository organization
- Share project layout

---

## Best Practice

Run

```powershell
tree /f
```

after creating new folders to verify the repository structure.
