# Day 6 - PowerShell Commands for Git

## Objective

Learn the PowerShell commands commonly used while working with Git repositories on Windows.

## Topics Covered

- Check if files or folders exist
- View files and folders
- View hidden files
- Delete files and folders
- Display project structure

## Files

- notes.md
- test-path.md
- get-childitem.md
- remove-item.md

## Outcome

After completing Day 6, you will be able to:

- Navigate your Git repository using PowerShell.
- Verify files and folders.
- Delete unwanted files safely.
- View the complete project structure.
