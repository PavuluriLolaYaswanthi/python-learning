# Git Stash vs Git Commit

| Feature | git stash | git commit |
|----------|-----------|------------|
| Temporary storage | ✅ | ❌ |
| Saves history | ❌ | ✅ |
| Appears in commit log | ❌ | ✅ |
| Used for unfinished work | ✅ | ❌ |
| Used for completed work | ❌ | ✅ |
| Can be shared | ❌ | ✅ |

---

## When to Use Stash

- Switching tasks
- Emergency bug fixes
- Temporary work

---

## When to Commit

- Completed features
- Bug fixes
- Documentation
- Stable code

---

## Recommendation

Use **Git Stash** for temporary work.

Use **Git Commit** for completed work.
