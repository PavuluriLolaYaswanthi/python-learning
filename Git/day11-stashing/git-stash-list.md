# git stash list

## Purpose

Display all saved stashes.

---

## Syntax

```powershell
git stash list
```

---

## Example

```text
stash@{0}: On main: Login Feature

stash@{1}: On main: Dashboard UI
```

---

## Useful Commands

```powershell
git stash

git stash list

git stash pop

git stash apply
```
