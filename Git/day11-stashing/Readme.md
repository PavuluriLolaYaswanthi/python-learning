# Day 11 - Git Stashing

## Objective

Learn how to temporarily save unfinished work without creating a commit.

## Topics Covered

- What is Git Stash?
- Create a stash
- View stashes
- Apply a stash
- Pop a stash
- Delete stashes
- Clear all stashes
- Stash Workflow
- Stash vs Commit

## Outcome

After completing this lesson, you will be able to:

- Save unfinished work temporarily.
- Switch branches safely.
- Restore saved work.
- Manage multiple stashes.
- Know when to use stash instead of commit.
