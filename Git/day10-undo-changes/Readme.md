# Day 10 - Undo Changes in Git

## Objective

Learn how to safely undo changes in Git without losing important work.

## Topics Covered

- git restore
- git reset
- git revert
- git diff
- Reset vs Revert
- Undo Workflow

## Files

- notes.md
- git-restore.md
- git-reset.md
- git-revert.md
- git-diff.md
- reset-vs-revert.md
- undo-workflow.md

## Outcome

After completing this lesson, you will be able to:

- Undo changes to files.
- Unstage files.
- Undo commits.
- Reverse commits safely.
- Compare file changes.
- Choose between reset and revert.
